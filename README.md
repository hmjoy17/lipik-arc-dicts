# lipik-arc-dicts

Dictionaries for the Lipik Arc keyboard, served from here so the app does not depend on third-party repos.

## Contents (`dictionaries/`)

| File | Language |
|------|----------|
| main_bn.dict | Bengali |
| main_en_us.dict | English (US) |
| main_en_gb.dict | English (UK) |
| main_hi.dict | Hindi |

Binary dictionaries are mirrored from HeliBoard's dictionary collection.
The Lipik Phonetic dictionary is served separately from the `lipik-dict` repo.

## Download URL pattern

`https://raw.githubusercontent.com/hmjoy17/lipik-arc-dicts/main/dictionaries/<name>.dict`
